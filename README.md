ЛАБОРАТОРНАЯ 1 ЗАДАЧА 3:  Монстры на столе
Есть прямоугольный стол размером N × M. В некоторых клетках сидят монстры. Всего
монстров k. Каждый монстр смотрит в одно из четырёх направлений (N, E, S, W). По
команде все монстры начинают двигаться в своём направлении до края стола. Двигаются
одновременно и не мешают друг другу. (если я понял правильно, то зомби могут пересекаться)
Нужно посчитать количество клеток стола, на которых побывает ровно один монстр,
включая начальные позиции и конечные.
Входные данные
N M
k (количество монстров)
для каждого монстра: x_i y_i направление (N/E/S/W)
Выход
количество клеток, посещённых ровно одним монстром. 
(все клетки, в которых побывал только один монстр)

мы всегда двигаемся только в 1 направление, поэтому одна из величин будет фиксировать
и не учитывается в подсчётах    
выбрали East как направление => двигаемся только вправо (меняем x)
выбрали North как направление => двигаемся только вверх (меняем y)
выбрали South как направление => двигаемся только вниз (меняем y)
выбрали West как направление => двигаемся только вправо (меняем x)

про реализацию Board.java:
 - для проверки количества посещений клеток создал двумерный массив visits
   при каждом попадание в клетку x_i, y_i visits[][]++, поэтому легко проверить все клетки,
   посещённые только один раз сравнением с единицой метода getVisits

про реализацию Monster.java: 
 - реализован move через булево значение для того, чтобы проверять, не выходим
   за границу поля через метод isInside
 - newX и newY, чтобы монстр не выходил за границу 
   то есть мы делаем проверку с значением больше и только
   потом заменяем исходное значение новым, если прошло проверку
